> **Веб-приложение (PWA) для бортовой экспресс-диагностики, высокоскоростного логирования телеметрии и управления исполнительными механизмами автомобиля Lada Priora (двигатель ВАЗ-21126 16V, ЭБУ Итэлма М73) прямо с iPhone через адаптер ELM327 BLE.**

🚀 **Запуск в один клик:** [swmenz.github.io/OBD-Scanner-M73](https://swmenz.github.io/OBD-Scanner-M73/)

---

## 📱 Основные возможности

* **Скоростной опрос до ~12 Гц:** оптимизированный однокадровый запрос KWP2000 (`21 01`), транслирующий все базовые параметры двигателя, счетчики пропусков по цилиндрам и коррекции смеси за 80 мс.
* **Экспорт в Microsoft Excel (`.xlsx`):** запись поездки в файл Excel с русскоязычными колонками телеметрии, готовый для анализа в Excel или сторонних лог-анализаторах (совместимо с форматом OpenDiag).
* **100% Offline-работа (PWA):** приложение кэшируется в Service Worker (`cache: 'reload'`), запускается без доступа к интернету на трассе или в гараже и не зависит от сторонних CDN.
* **Дизайн Apple Automotive (Liquid Glass 2026):**
  * Глубокий True OLED Black (`#000000`) без выгорания экрана в темное время суток.
  * Плавные аппаратные шкалы (120 FPS на экранах ProMotion).
  * Интеллектуальная индикация детонации, пропусков воспламенения и температуры.
  * Парящий стеклянный док с оригинальными векторными символами (SF Symbols).
* **Диагностика ошибок (DTC):**
  * Чтение кодов неисправностей из статической памяти и памяти ошибок ЭБУ М73.
  * Расшифровка кодов ошибок на русском языке с подробным описанием причины.
  * Сброс кодов ошибок ЭБУ по команде `14 FF 00`.
* **Каналы АЦП и проверка датчиков:**
  * Напряжение покоя ДМРВ 116 (с индикатором эталона 0.996–1.020 В для оценки износа).
  * Напряжения ДПДЗ, ДТОЖ, датчика кислорода и бортовой сети.
* **Тесты исполнительных механизмов:**
  * Реле вентилятора охлаждения 1-я скорость (5 секунд).
  * Реле вентилятора охлаждения 2-я скорость (5 секунд).
  * Реле бензонасоса (принудительное включение).
  * Лампа индикатора «Check Engine» (MIL).
* **Сброс с инициализацией:** сброс накопленных таблиц самообучения по топливу и УОЗ контроллера М73 к заводским значениям.
* **Интерактивный терминал ELM327:** сырой обмен AT/KWP командами с контроллером с кольцевым буфером на 300 строк.

## ⚡ Инструкция по подключению

1. Подключите адаптер **ELM327 BLE** в диагностический разъём OBD-II автомобиля (расположен в ногах переднего пассажира за центральной крышкой консоли).
2. Включите зажигание автомобиля (или заведите двигатель).
3. На iPhone откройте приложение **Bluefy** и перейдите по адресу:
   ```
   https://swmenz.github.io/OBD-Scanner-M73/
   ```
4. Нажмите синюю кнопку **«Подключить»** в верхнем правом углу.
5. В появившемся диалоге iOS выберите ваш Bluetooth-адаптер (обычно называется `OBD BLE`, `IOS-Vlink`, `Viecar` или `OBDII`).
6. После автоматического согласования протокола KWP2000 (Fast Init на скорости 10400 бод) индикатор станет зелёным, и на панели отобразится телеметрия реального времени.

## 📊 Режимы опроса телеметрии

* ⚡ **Спорт (макс. скорость, ~12 Гц):** опрашивается только Кадр 1 (`21 01`). Время одного цикла всего ~80 мс — идеально для записи разгонов, логов откатки и динамических тестов.
* 📋 **Все датчики (~6 Гц):** опрашиваются Кадр 1 (`21 01`) и каналы АЦП (`21 03`). Время цикла ~160 мс.
* ⚙️ **Выборочно:** настраиваемый опрос нужных кадров данных.
