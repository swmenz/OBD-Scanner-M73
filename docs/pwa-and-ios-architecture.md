# Архитектура PWA и фоновая работа на iOS

Документ описывает программную архитектуру Progressive Web App (PWA), интеграцию с Web Bluetooth API и решение специфических проблем выполнения JavaScript в среде **Apple iOS WebKit**.

---

## 1. Специфика платформы iOS и ограничения WebKit

Операционная система iOS накладывает строгие ограничения на фоновое выполнение сторонних веб-приложений:

1. **Отсутствие Web Bluetooth в Safari:** Apple не включает Web Bluetooth API в стандартный браузер Safari. Для работы с периферией BLE требуется браузер со встроенным мостом WebKit ↔ CoreBluetooth (рекомендуется **[Bluefy — Web BLE Browser](https://apps.apple.com/app/bluefy-web-ble-browser/id1492822055)**).
2. **Агрессивное усыпление фоновых вкладок:** при переключении пользователя в навигатор, мессенджер или экран блокировки WebKit останавливает таймеры `setTimeout` и `setInterval`, замораживает цикл отрисовки `requestAnimationFrame` и сбрасывает активные GATT-соединения Bluetooth Low Energy.
3. **Монополизация сетевых интерфейсов Wi-Fi:** диагностические адаптеры с Wi-Fi отключают сотовую передачу данных на iPhone, лишая водителя онлайн-карт и связи.

Priora Diag M73 ProLog решает эти проблемы на архитектурном уровне без необходимости джейлбрейка или нативной сборки под iOS.

## 2. Комплекс непрерывности (Background Continuity)

В модуле [`app.js`](../app.js) развернуты три взаимодополняющих подсистемы:

```
┌────────────────────────────────────────────────────────┐
│                   Жизненный цикл сессии                │
└──────────────────────────┬─────────────────────────────┘
                           │
         ┌─────────────────┼─────────────────┐
         ▼                 ▼                 ▼
 ┌───────────────┐ ┌───────────────┐ ┌───────────────┐
 │ Ambient Audio │ │ Screen Wake   │ │ Silent BLE    │
 │ Keeper        │ │ Lock          │ │ Reconnect     │
 │ (Фоновый ток  │ │ (Удержание    │ │ (Восстановле- │
 │  JS-таймеров) │ │  подсветки)   │ │  ние сессии)  │
 └───────────────┘ └───────────────┘ └───────────────┘
```

### Фоновый аудио-кипер (Ambient Audio Keeper)

Для предотвращения заморозки JavaScript-процесса при сворачивании браузера используется класс `BackgroundKeeper`:

* Через Web Audio API генерируется аудио-контекст `AudioContext` с цикличным воспроизведением 2-секундного буфера тишины (PCM с амплитудой 0).
* Аудиосессия регистрируется с типом `ambient`:
  ```javascript
  if ('audioSession' in navigator) {
    navigator.audioSession.type = 'ambient';
  }
  ```
* **Практический эффект:** тип `ambient` указывает операционной системе iOS CoreAudio, что веб-приложение воспроизводит фоновый неслышимый поток, **не требующий эксклюзивного захвата аудиоустройства**. Приложение продолжает работать в фоне, не прерывая и не заглушая музыку в Apple Music, Яндекс Музыке, Spotify или голосовые указания Яндекс Навигатора.

### Удержание экрана (Screen Wake Lock API)

Класс `WakeLockManager` при активном подключении к ЭБУ запрашивает системную блокировку засыпания экрана через стандартный вызов:
```javascript
this.wakeLock = await navigator.wakeLock.request('screen');
```
При установке iPhone в автомобильный держатель экран не гаснет, позволяя водителю непрерывно контролировать температуру ОЖ, напряжение бортсети и детонацию. При закрытии сессии блокировка экрана освобождается автоматически.

### Бесшовный авто-реконнект (Silent BLE Reconnect)

Если связь Bluetooth прерывается (например, при кратковременном удалении от автомобиля или аппаратной перезагрузке адаптера), драйвер сохраняет объект `BluetoothDevice` в оперативной памяти:
* Слушатель событий `visibilitychange` и `focus` перехватывает возвращение пользователя в приложение.
* Драйвер выполняет прямое переподключение `await device.gatt.connect()` без показа системного окна выбора устройства.
* Текущая сессия записи лога в `logger.js` **не прерывается и не сбрасывается** — новые кадры продолжают дописываться в ту же временную шкалу.

## 3. Офлайн-архитектура и хранилище данных

Приложение спроектировано по принципу **100% Offline First**:

```
[Пользователь] ──► [Service Worker] ──► [Cache Storage] (v52.1)
                          │
                   (Нет интернета)
                          │
                          ▼
            [Автономный запуск PWA]
                          │
                          ▼
             [Локальная база IndexedDB]
                          │
                          ▼
             [Генерация XLSX (SheetJS)]
```

### Сервис-воркер (`sw.js`)

* Сервис-воркер кэширует полный бандл приложения (`index.html`, `styles.css`, все `.js`-модули, локальную сборку `xlsx.full.min.js`, манифест и пиктограммы).
* Используется стратегия **Cache-First**: приложение загружается мгновенно даже в зонах полного отсутствия сотовой связи (гаражные боксы, подземные парковки, загородные трассы).

### Энергонезависимый логгер (`logger.js`)

* При включенном тумблере «Автозапись» телеметрия автоматически буферизуется в памяти.
* При выключении зажигания или обрыве связи класс `TripStorage` сбрасывает буфер в локальную базу данных **IndexedDB** (`Priora_M73_Logs`, хранилище `trips`).
* Сохраняются последние 10 поездок с метаданными (время старта, длительность, пиковые обороты, количество точек).
* Формирование файлов `.xlsx` производится локально на процессоре смартфона через встроенную автономную сборку SheetJS без отправки данных на внешние серверы.

## 4. Модульная система виджетов и графический движок

Модуль [`dashboard-widgets.js`](../dashboard-widgets.js) реализует интерфейс настройки приборной панели в стиле виджетов мобильных ОС:

* **Режим редактирования (Jiggle / Wiggle Mode):** вызывается кнопкой редактирования в верхней панели. Позволяет изменять ширину карточек (1 колонка ↔ 2 колонки на всю ширину), удалять неиспользуемые параметры и добавлять новые из встроенной галереи датчиков.
* **Touch Drag & Drop:** оптимизированный обработчик сенсорных событий (`touchstart`, `touchmove`, `touchend`) с расчетом коллизий и плавной анимацией перемещения карточек без задержек.
* **Canvas-осциллограф:** высокочастотная отрисовка графика (ДК1, ДК2, ДМРВ, Обороты, Дроссель, УОЗ, Впрыск, Детонация) через `requestAnimationFrame` с аппаратным ускорением GPU, адаптивным авто-масштабированием (Auto-Scale) и нанесением пороговой линии стехиометрии 0.45 В.
* **Персистентность:** текущее состояние сетки и набор выбранных виджетов сериализуются в `localStorage` и мгновенно восстанавливаются при последующих запусках.
